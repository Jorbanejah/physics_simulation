<h1>Physics Simulation</h1>

<p>
  This repository explores a collection of classic physics problems and shows how simple textbook exercises can evolve into rich, realistic simulations.
  Each directory focuses on a familiar scenario — projectile motion, geometric optics, numerical integration, and more — and demonstrates how complexity
  naturally emerges once we relax ideal assumptions.
</p>

<p>
  Physics often begins with perfect worlds: no friction, no air resistance, point masses, ideal lenses. But the moment we introduce real‑world factors,
  the behavior changes dramatically.<br>
  How does a projectile’s trajectory deform under drag?<br>
  How can Snell’s law and geometry be used to simulate snow or layered refraction?<br>
  What happens when analytical solutions give way to numerical ones?
</p>

<p>
  As one of my teachers liked to say:
  <em>“Let’s build a better approximation of the world.”</em>
</p>

<hr>

<h2>🌌 What You’ll Find Here</h2>
<ul>
  <li>Classic physics exercises implemented from first principles</li>
  <li>Progressive complexity: ideal → realistic → challenging</li>
  <li>Clean, readable Python code designed for learning</li>
  <li>Visualizations that connect equations to intuition</li>
  <li>Opportunities to extend the models with new forces, media, or geometry</li>
</ul>

<hr>

<p>Each directory includes:</p>
<ul>
  <li>A baseline model (idealized physics)</li>
  <li>One or more extended models (drag, refraction layers, geometry, etc.)</li>
  <li>Plots or animations to visualize the results</li>
</ul>

<h2>🧠 Why This Repository Exists</h2>

<p>The goal is to show how:</p>
<ul>
  <li>Simple physics becomes complex physics</li>
  <li>Analytical solutions transition into numerical ones</li>
  <li>Code can reveal physical intuition</li>
  <li>Small changes in assumptions create big changes in behavior</li>
</ul>

<p>
  If you're learning physics, programming, or numerical methods, this repository gives you a playground to explore all three.
</p>
